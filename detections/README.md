# Detections

**Status: Planned for NCDL v1 - no custom detections implemented or validated yet.**

This directory will contain custom Wazuh detection logic built against validated Windows telemetry from `NCDL-DC01`. Each detection will record its data requirements, rule logic, ATT&CK mapping where supported, severity rationale, false-positive analysis, test method, observed result, known gaps, and [supporting evidence](../evidence/README.md).

A rule will not be marked validated until its expected matches and relevant non-matches can be reproduced.
