# Evidence

**Status: No evidence artifacts published in this repository yet.**

This directory will hold sanitized source artifacts such as log exports, query results, configuration validation, and integrity hashes. Use `YYYY-MM-DD_short-description` names and record source, capture time and timezone, collection method, asset, and redactions. Preserve original exports where safe and hash material artifacts with SHA-256 where practical.

The lab infrastructure and telemetry path are operational, but that fact does not substitute for repository evidence. Screenshots belong in [`assets/screenshots/`](../assets/screenshots/README.md). Fabricated or reconstructed evidence is not accepted. See the full [evidence standard](../docs/ARCHITECTURE.md#evidence-standards).
